# BALAJI — THE SERIES

Personal portfolio styled like a streaming series: pick a profile (Recruiter, Client, Developer), then browse About, Journey (seasons), Originals (projects), Skills and Contact. The section order and hero call to action change with the profile.

Not affiliated with, endorsed by or connected to Netflix. No Netflix logos or assets are used.

## Stack

Vite, React, TypeScript, Tailwind CSS 4, framer-motion, Lenis.

## Run

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Content

All text lives in `src/data/portfolio.ts`. The hero image is `public/balaji.png`.
